.. _overview-label:

Overview
======================

This section gives both an introduction to the language philosophy as well as an explanation of the intended uses.
It is meant to be read in order, and mainly targets:

* Users that would like to better understand how the language works
* Contributors that would like to be provided with explanations on design decisions
* Researchers that would like to find open problems with the language
