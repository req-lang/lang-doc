Overview
======================

The section gives both as introduction to the language philosophy as well as an explanation of the intented uses
It is meant to be read in order, and mainly targets:

* Users that would like to better understand how the language works 
* Contributors that would like be provided with explanations on design decisions 
* Researchers that would like to find open problems with the language
