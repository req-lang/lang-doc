req-vscode
======================

*req-vscode* is the VSCode editor language extension.
It is free and open-source, it is distrbuted in vsix.

To install it, follow the instructions in the :ref:`getting-started-label` guide.

.. note::

   This extension is still under active, development feel free to contribute at https://github.com/req-lang

Features
***********************

* Syntax coloring of req files
