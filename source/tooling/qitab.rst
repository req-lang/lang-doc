Qitab
======================

*Qitab* is the commercial development environement for the req language.
It is distributed as a licensed desktop application.

.. note::

  Qitab is currently in early-acceess, see: https://qitab.io, contact: contact@qitab.io to get in touch

Features
***********************

Qitab goes beyond pure edition by providing advanced:

* AI integration 
* import and export features
* document generation
* diagnostics and correction suggesiton
* collaboration features
* modeling features

It is design to be the full scope editor for the req language, allowing user to maximize language utility for each :ref:`use-cases-label`
