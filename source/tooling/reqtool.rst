reqtool
======================

*reqtool* is the principal tool for working with req files. 
It is free and open-source and serves as a pilot implementation for the req language.

However, reqtool attempts to put the emphasis on optimization in order to be usable in real-world context with convient experience.

To install it, follow the instructions in the :ref:`getting-started-label` guide.

.. note::

   The tool is still under active, development feel free to contribute at https://github.com/req-lang

Features
***********************

* req files diagnostics checking for defects in the specification ``check``
* req files formatting to ensure standard format ``fmt``
